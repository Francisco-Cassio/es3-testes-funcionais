## Estrutura do Repositório
- `matriz_casos_de_teste.csv`: Especificação dos casos de teste (partição de equivalência, valor-limite e tabela de decisão)
- `pacote-A/`: Sabor Express e Portal de Matrícula Acadêmica (`app/`, `exemplo/` e `desafio/`)
- `pacote-B/`: Portal ADS e Inscrições em Minicursos (`app.py`, `web/`, `exemplo/` e `desafio/`)
- `projeto-anterior/`: Testes funcionais E2E da aplicação **Clínica Agenda** (Django REST + Vue 3)
- `resultados/`: Relatórios HTML e JUnit XML das 3 execuções de cada suíte
